Documentation / Features

Interface

In a text game the scrolling text is the interface, so Emunah's panels sit around it and never over it. They draw from the same state the curing engine acts on, so what you see is what Emunah is about to do.

Layout

WhereWhat
LeftThe room, your afflictions and your defences, one above the other.
RightChat in tabs, and the map beneath it.
BottomThe combat HUD: target, vitals and the balance strip.
TopA scrolling ticker for anything you must not miss.

The left column divides its height by what each section actually holds, so a crowded room or a long defence list is shown in full. When it cannot all fit, defences go to more columns and short item names pair up before anything scrolls. The game text's borders follow the panels, so a panel you resize by hand never covers a line of text.

Room

Where you are, with the room's number, exits and any shop or bank. Then three groups, each with a count:

  • People, coloured the same way names are coloured in the game text.
  • Mobiles, each one clickable. A filled dot means the hunt will attack it and a hollow one means it will not; a click adds or removes that kind from the area's kill list.
  • Items, with identical items collapsed into one row and a count.

The game leaves out anyone shrouded, hidden or phased, so the people list is everyone the game admits to, not necessarily everyone there.

Afflictions

Afflictions are listed in curing order, and each row answers what Emunah is doing about it:

The row saysMeaning
curingThe cure has been sent and the game has not answered yet.
nextEverything is ready; it goes out on this prompt.
1.4sIts balance is recovering, and this is how long is left.
× paralysisIts only way is shut by another affliction, named.
a reasonWhy Emunah refused it, such as "in the rift", so a refusal never looks like a hang.

A filled dot means the server reports the affliction; a hollow one means only the game text has, and it is waiting for the server to confirm it. Above the rows, any state that holds every command (stunned, asleep, prone, unconscious) shows as a pill. Below them, one line per lock reads off what is shut and by what.

Defences

What keep-up is still owed comes first, then everything that is up, with a count of each in the title. See Defence maintenance.

The combat HUD

Three rows, directly above the command line:

  1. Buttons, target and status. HUNT starts or stops a hunt, and is lit while one runs. PAUSE pauses or resumes curing and defences together, the same as pp, and reads PAUSED in red while they are off. Then your target's health bar, PvP and its target, and the commands sent and not yet answered.
  2. Vitals. Health, mana, endurance and willpower, each with its percentage and its change since the last prompt.
  3. Balances. The balance strip, then experience and your class's own figures, such as devotion for a Priest.

The balance strip

One cell for balance and equilibrium, then one for each curing balance: herb, salve, sip, purgative, smoke, focus, moss and tree.

The cellMeans
Green, with a tickReady.
Blue, with an arrowA command was sent on it and the game has not answered.
Grey, with secondsRecovering. The game's own figure where it states one.
Red, with a crossShut by an affliction, or by paralysis.
DimNothing to use, such as the tree cell with no tree tattoo.

The strip applies exactly the rules the queue does, so it cannot show a balance as ready that Emunah would not send on.

Chat, map and ticker

Channels are captured into tabs: tells, city, house, market, says and the rest, configurable with ui.chatTabs. Capture and display are separate, so one failing never takes the other with it. The map is Mudlet's own, embedded below the chat; emset ui map off hides it.

The ticker across the top scrolls continuously, up to three messages at once, for notices that must not scroll away, such as having no shield wielded. A persistent label in the game window says when curing or keep-up is paused, so a system quietly doing nothing is impossible to miss.

Names in the text

Known people are coloured where they appear in the game text, by what they are to you: dark red for your city's enemies, green for allies, otherwise their city, with any other enemy underlined. Weight carries the rest, such as a Dragon or someone you marked as important, so both can be read at a glance. Your own name is never highlighted. See People and names.

Keys

KeyDoes
NumpadMovement in all eight directions, 0 and . for in and out, − and + for up and down, and 5 to look, with or without Num Lock. keys.numpad turns it off.
Ctrl + F5Reload Emunah.
F11Start hunting.
F12Stop hunting and retreat three rooms the way you came.

What it costs

Mudlet runs every package on one thread, so a repaint is time the client is not reading or sending. Emunah's panels paint once, after each packet has been handled, never before a cure has been sent, and not at all when nothing they show has changed. Countdowns redraw every 0.2 seconds only while something is counting (ui.refresh). See Performance for the measurements.

emset ui                # whether the panels and the map are on
emset ui rebuild        # rebuild every panel; fixes one that is missing or stuck
emset ui map on|off

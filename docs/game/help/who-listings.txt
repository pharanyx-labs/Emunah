WHAT IS ESTABLISHED HERE
- Header is exactly "You are:". Entries follow, one per line, each ending in a full stop.
- TWO FORMS, and the difference matters:
    "afflicted by <name>."   an affliction
    "<name>."                a bare state
  In this sample the bare one is `blind`, which the character was holding deliberately as a
  defence. So a bare line is NOT safe to treat as something to cure. Only "afflicted by"
  lines are read as afflictions; bare lines are reported and left alone.
- The block ends at the cost line, "Equilibrium used: 1.00s." Entries are lowercase and
  that line is not, which is what lets the parser stop without a separate terminator.
- Names may contain SPACES: "thin blood". Emunah's affliction table has no entry for it
  under any spelling, so DIAG found something the cure table does not cover -- which is
  exactly the sort of gap reading this output is meant to surface.

WHAT IS NOT ESTABLISHED

  coincidence of this one sample. The conservative reading is used until a second sample
  says otherwise.
